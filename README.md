# 简单早晚安

`astrbot-plugin-easygreeting` 是一个 AstrBot 插件：每天在早安、晚安各自的时间窗口内，随机选择时间，调用聊天模型生成问候，再发送到白名单中的群聊或私聊。

## 功能

- 早安、晚安各自配置基准时间、提前/延后的随机范围和提示词，自带默认提示词。
- 每个白名单会话独立随机，每个基准日期各发送一次早安和晚安。
- 群聊和私聊独立开关、独立白名单；默认白名单均为空。
- 可选择专用聊天模型，也可使用目标会话当前配置的聊天模型。
- 保存随机计划和发送状态，正常重启、重载不会重新抽取或重复发送。
- 支持跨午夜的时间窗口、时区设置以及管理员测试指令。

## 安装

需要 **Python 3.11+**、AstrBot **4.9.2 或以上的 4.x 版本**，以及支持主动发送消息的平台。

1. 将插件文件夹放入 AstrBot 的 `data/plugins/` 目录，或者在 WebUI 中上传本插件的 ZIP 包。
2. 在 AstrBot 的 Python 环境中安装 `requirements.txt` 中的依赖。默认 `UTC+08:00` 时区使用 Python 标准库；`tzdata` 用于 Windows 等环境的 IANA 时区名称。
3. 在 WebUI 的插件页重载“简单早晚安”，进入插件配置并选择一个已配置的聊天模型。
4. 设置早安、晚安时间和随机范围，然后添加要接收问候的会话白名单。

插件无需额外的 API Key，使用 AstrBot 中已经配置的模型。AstrBot 需要持续运行，才能执行定时发送。

## 配置示例

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| 时区 | `UTC+08:00` | 北京时间，也可填写 `Asia/Shanghai` 等 IANA 时区 |
| 聊天模型 | 留空 | 使用目标会话当前配置的模型；也可明确选择 |
| 早安时间 | `08:00` | 24 小时制 |
| 早安随机范围 | 提前 30、延后 30 分钟 | 在 `07:30～08:30` 内随机触发 |
| 晚安时间 | `23:00` | 24 小时制 |
| 晚安随机范围 | 提前 30、延后 30 分钟 | 在 `22:30～23:30` 内随机触发 |
| 群聊/私聊白名单 | 空列表 | 空列表不向任何会话自动发送 |

时间按分钟配置，窗口包含结束的这一分钟；例如 `08:30` 包括 `08:30:00～08:30:59`。两项随机分钟数都设为 `0`，则在基准时间的这一分钟内触发。定时触发的是模型请求，实际收到消息还需要模型生成和平台投递的时间。模型超时或生成后已离开窗口时，不会补发。

提前和延后各支持 `0～720` 分钟，两者之和必须小于 `1440`。跨午夜时，以**基准时间所属日期**记一次问候。例如，晚安设为 `00:10`、提前 30 分钟，可能在前一天 `23:40` 之后触发。

## 白名单与指令

最方便的方式：由 **AstrBot 管理员**在目标群聊或目标私聊中发送 `/早晚安开启`。

| 指令 | 作用 |
| --- | --- |
| `/早晚安开启` | 将当前会话加入对应的白名单 |
| `/早晚安关闭` | 将当前会话从对应的白名单移除 |
| `/早晚安会话` | 显示当前会话的完整标识，方便复制到配置 |
| `/早晚安状态` | 查看是否启用、早晚安时间、下次随机计划 |
| `/早晚安测试 早安` | 立即调用模型，向当前会话主动发送一条早安 |
| `/早晚安测试 晚安` | 立即调用模型，向当前会话主动发送一条晚安 |

所有指令均要求 AstrBot 管理员权限。指令示例使用默认 `/` 唤醒前缀；修改过前缀时按实际前缀发送。测试指令是手动操作，不占用每日次数，也不要求将当前会话加入白名单。

白名单填写的是 **完整会话标识**，例如：

```text
你的平台实例ID:GroupMessage:群聊会话ID
你的平台实例ID:FriendMessage:私聊会话ID
```

请使用 `/早晚安会话` 获取真实值，不能只填写群号或 QQ 号。同一个群在不同机器人实例中是不同会话。群聊会话只能放入群聊白名单，私聊会话只能放入私聊白名单。

`/早晚安开启` 只添加白名单。插件总开关、群聊/私聊开关和早安/晚安开关仍以配置面板为准；定时计划通常在 5 秒内更新。

## 提示词

早安、晚安分别有可编辑的提示词，留空时使用默认值。可以在里面指定风格、角色和称呼，例如：

```text
你是一位语气活泼、喜欢用颜文字的朋友。请发一条不超过40字的早安，
称呼对方为“小伙伴”，祝对方今天顺利。只输出要发送的消息正文。
```

每次请求还会提供问候类型、当前本地时间及群聊/私聊场景。生成使用独立模型请求，表达风格由这里的提示词决定，不读取或写入目标会话的聊天历史。

## 重启与异常处理

- 计划和发送状态保存在 AstrBot 的插件 KV 存储中，不放在插件代码目录。
- 配置有误时插件仍会加载，调度会每 5 秒重试；`/早晚安状态` 会提示错误，修正配置后自动恢复。
- 关闭群聊或私聊开关时，对应白名单中的旧条目不会影响另一类会话。
- 发送占位写入失败时不会误发；存储恢复后会在下一次调度中重试。
- 首次启用时，若当天仍在窗口内，从剩余时间中随机；窗口已经结束则从下一次开始，不补发过去的问候。
- 已保存的随机时间在重启后保留；如果该时间已经过去，但还在窗口内，则尽快触发。
- 模型生成失败最多尝试 3 次，间隔至少 60 秒，且只在窗口内继续。
- 发送前再次检查白名单、开关和窗口。生成过程中关闭会话，也会阻止后续发送。
- 为避免重复，在调用平台发送前记录发送占位。若恰好在发送阶段中断，或平台发送失败，当天这条问候不会自动重试，可能漏发一次。
- 修改时间窗口后，尚未发送的计划会重新抽取；当天已发送的问候不会再次发送。

主动发送的支持情况取决于消息平台和账号权限；AstrBot 官方 QQ 机器人等平台可能限制主动消息。请先用测试指令在实际接入的平台验证；测试与自动问候使用相同的主动发送接口。正常情况下，每个会话每天生成两条问候，失败重试和手动测试会增加模型调用次数。
